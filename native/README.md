# Axon

macOS 原生 SSH 客户端，使用 SwiftUI/AppKit、SwiftTerm 和 Citadel。独立工程位于 `native/`，应用名为 **Axon**，原有 Electron Tabby 保留。原生工程版本从 **0.1.0** 开始，当前版本为 **0.9.1**；不是上游 Tabby 1.0.237 的重新编号。

## 使用

需要 Apple Silicon 和 macOS 15 或更高版本。打开 `dist/Axon.app`，新建主机或者通过设置 →「导入与导出」迁移 SSH 配置。应用使用独立配置 `~/Library/Application Support/TabbyNative/workspace.json`，每次保存维护 `.backup`。密码、私钥口令和粘贴的私钥文本使用 macOS 钥匙串，不写入 JSON。

- 主机卡片：搜索、分组、标签、收藏、创建、修改、删除。
- 终端：本地登录 Shell、SSH 标签页、双终端分屏（⌘D）、密码 / OpenSSH Ed25519 与 RSA 私钥、跳板机链、断线重连、窗口尺寸、中文输入、复制粘贴、终端搜索（⌘F）。切换主机页面保留连接。
- SFTP：本地 / 远程或本地 / 本地双栏，右栏内选择主机；路径导航与历史、排序与筛选、隐藏文件、目录收藏、多选上传下载与本地复制、拖放、递归目录、中文名称、空文件、传输进度与速度、取消与重试。
- 监控：主机库侧栏概览、Linux 主机资源与进程、网络与 IP、NVIDIA GPU、Docker 只读详情；终端右侧状态与代码片段共用现有连接。
- 代码片段：本地保存、分组、搜索与排序、多行编辑、复制、重复、移除；支持 `{{参数}}`、默认值、类型校验和展开预览。保险库和终端右侧 `{}` 面板共用片段。选择一个或多个已连接终端插入或运行；插入不按回车，未启用 Bracketed Paste 的终端不直接插入多行内容。
- 工作场景：保存终端顺序、双栏布局、初始目录、常用文件／日志路径和转发规则；每个场景打开为独立工作区标签，内部切换终端、SFTP 和日志。
- 运维工具：终端与 SFTP 双向目录导航、UTF-8 日志跟随／搜索／过滤／导出、目录精确比较与固定差异上传。
- 代理与转发：本地／远程固定 TCP 转发，以及动态 SOCKS5 TCP 代理与远端 DNS；规则默认停止，可由场景显式启动。
- 文件操作：创建文件与目录、重命名、八进制权限、删除、复制路径、UTF-8 文本编辑（最大 2 MB）。本地删除进废纸篓；远程删除显示确认。编辑保存保留旁边的 `.backup-UUID` 文件。
- 传输：写入独立临时文件后提交；覆盖前确认；失败尝试恢复旧文件。符号链接不跟随，防止意外遍历目录或覆盖链接目标。
- SSH 首次连接确认 SHA256 主机指纹；之后主机密钥变化拒绝连接。
- 导入识别 SSH 主机、端口、用户名、分组、私钥路径和跳板机关系，重复主机合并。加密保险库、SSH agent、代理命令、端口转发与登录脚本不迁移，请使用密码或私钥配置。

工作区按本机 Termius 10.1.3 的浅色界面调整：主背景 `#EDF2F3`、侧栏 `#F7F9FC`、白色卡片、深色顶部 `#303249`、蓝色强调 `#2E91EC`。终端保留原始 Dracula Green：前景 `#00CC74`、背景 `#1e1f29` 和原始 16 色；保留 Menlo 19、250000 回滚、稳态块状光标、选中复制、右键与中键粘贴、粘贴去除首尾空白。读取配置不再自动覆盖配色或字体。界面语言按系统首选语言选择中文或英文，也可以手动指定。分析和全局快捷键关闭，不自动创建或恢复终端。

界面参考 Termius 的顶部工作区标签、窄侧栏、搜索与操作栏、分组卡片、横向主机卡片和右侧详情面板布局，采用 Axon 图标和自己的配色。没有使用 Termius 品牌素材、服务或云同步。此工程提供桌面终端和文件管理工作流，尚不包含 Termius 的云端团队协作、移动端、SSH agent、硬件密钥和 mosh。

终端渲染采用 SwiftTerm 原生实现，原 Electron 的 xterm canvas / CSS 配置不能直接移植。字体粗细与最小对比度由 SwiftTerm 原生渲染处理，原 xterm 的 300 / 400 字重和对比度 4 没有对应的独立设置。私钥支持 OpenSSH 格式；老式 PEM 密钥请转换为 OpenSSH。仅支持现代服务器提供的 NIO/Citadel 加密算法；RSA 主机密钥的 RSA-SHA2 协商尚受底层库限制，优先使用 Ed25519 / ECDSA 主机密钥。

## 0.9.0 运维工作流

- **外部编辑**：在文件列表右键选择「使用外部编辑器…」，默认使用系统关联应用，也可在编辑任务中选择 TextStack、TextEdit 或其他编辑器。在 SFTP 底部「外部编辑任务」检查保存后的差异，再确认回传；回传校验远端原内容与属性，保留 `.backup-UUID`，沿用权限。工作副本保存在 `~/Library/Application Support/TabbyNative/ExternalEdits/`，退出或失败仍保留。只支持不含 NUL 的普通文本文件，最大 32 MiB；不自动上传，不修改 TextStack。
- **传输续传**：失败任务保留暂存文件，重试先逐块验证已有前缀与源文件一致，再继续写入；支持同一主机、账号和跳板路线重连后重试。源／目标发生变化会拒绝提交，可选择重新开始。取消／清除任务清理暂存；队列和续传信息仅本次运行有效。
- **关键词规则**：设置 →「关键词规则」，支持普通文本／正则、大小写、前景／背景色、粗体、排序与实时预览，以及全局／分组／主机范围。主机规则优先于分组和全局；重叠匹配保留先命中的规则。装饰只覆盖可见字符，不改变复制、搜索和导出的终端原文；选中文本时暂停装饰。匹配有长度、数量与时间限制。
- **Shell 与历史**：Bash/Zsh 会话钩子记录目录、退出状态和耗时，可筛选失败命令；设置中可配置保留条数（100–50000）、按行排除关键词及长命令完成通知（默认关闭）。保留敏感命令过滤与令牌校验，不写入用户 Shell 配置。已有 Bash DEBUG trap 时保留原 trap，无法提供完整命令计时。
- **持久会话**：主机编辑或工作场景中启用持久会话，可指定 tmux 名称；服务端需要 tmux 3.3+ 和 Bash。断线／关闭标签只分离，重新连接同一名称恢复原屏幕与远端进程；显式「结束远端会话」才终止程序。拒绝接管同名的非 Axon 会话。不自动启动或恢复所有本地标签，服务器重启后的进程恢复不在此范围。
- **批量任务中心**：紧凑主机列表与命令编辑工作台，结果表格按状态筛选，选中后查看和复制输出；按主机／分组／标签选择目标，支持代码片段参数预览，1–16 并发、1–3600 秒超时、实时标准输出与错误、退出状态、耗时、取消、按原命令重试失败项和 JSON 结果导出。每台主机使用独立 SSH 通道，沿用认证、跳板机与指纹验证；不提供交互输入。服务器必须有 GNU `timeout`（macOS 可为 `gtimeout`），缺失时不会执行任务。单目标输出最多 1 MiB；结果仅保留在当前运行中，需自行导出。

## 开发与打包

Xcode 27 / Swift 6.4 已验证。依赖提交固定于 `Package.resolved`。

```sh
swift build --package-path native
swift test --package-path native
native/scripts/package.sh release
```

产物为 `native/dist/Axon.app` 与 `Axon-0.9.1-mac-arm64.zip`。脚本包含依赖资源、Axon 图标和版本信息，并优先使用本机已有的 Apple 代码签名身份；可用 `AXON_SIGN_IDENTITY` 指定身份，没有可用证书时才回退至 ad-hoc。本机使用已有 Apple Development 身份，以便更新后 macOS 仍识别为同一应用。不含 Developer ID 公证；跨电脑公开发布需要发布证书与公证。不会自动覆盖 `/Applications/Tabby.app`。

## 集成测试

测试服务器仅监听 127.0.0.1，生成一次性的主机 / 用户密钥，文件位于新的临时目录。使用 Paramiko 5 的测试环境：

```sh
python3 -m venv /tmp/tabby-native-test-python
/tmp/tabby-native-test-python/bin/pip install paramiko
/tmp/tabby-native-test-python/bin/python native/scripts/test-server.py /tmp/tabby-native-test-server.json
# 另一个终端：
TABBY_TEST_SERVER=/tmp/tabby-native-test-server.json swift test --package-path native
```

测试覆盖配置默认值、保存与备份、导入去重、路径校验、隐藏文件与导航失败、本地递归传输、空文件、取消、真实密码 SSH/SFTP、800 KB 中文文件上传下载字节一致、权限和重命名、Ed25519 登录 / PTY / 尺寸变更，跳板机通道，以及主机密钥变化拒绝。未设置测试服务器时集成测试明确跳过。

监控测试还覆盖采样时基、计数重置、部分能力失败、参数脱敏、生命周期、超时取消及原生界面布局。回环服务器可设置 `TABBY_TEST_MONITOR_SAMPLE` 为 `native/scripts/fixtures/monitoring-linux-16cores.txt`，使监控 exec 返回合成 Linux 数据；测试进程同时设置该变量和 `TABBY_TEST_SERVER` 可运行监控 SSH 集成测试。该合成响应仅用于测试，不是服务器硬件验收。实际采集脚本在 macOS 回环主机上验证明确不支持的路径。

## 0.3.0 本地保险库：主机、分组与凭据

新增本地凭据库，可创建、编辑和移除密码身份／OpenSSH 私钥身份。凭据元数据存储在 workspace.json，密码或私钥口令仅保存到 macOS 钥匙串；私钥可以选择本地文件路径，或粘贴文本并保存到 macOS 钥匙串。主机详情选择“引用凭据”后，后续连接解析共享身份最新值；移除共享身份前将其转为主机独立凭据。主机右键支持复制和移动到分组，侧栏分组右键支持重命名及解散（保留主机）。旧工作区缺少凭据数组也能加载，原主机 ID 和密码不自动迁移。

本轮范围按用户确认只包括主机、分组、凭据管理。多保险库、分组继承、私钥生成／内置私钥文件存储、硬件凭据、端口转发和命令片段未实现。

## 0.3.1 端口转发与日志

本地及远程固定 TCP 转发规则支持创建、编辑、启动、停止与移除，持久化规则但重启不自动监听。启动使用已有连接，或创建所选主机的 SSH 会话；支持既有共享凭据和跳板机。监听默认 127.0.0.1，目标端根据方向解析。停止关闭该规则的监听与子连接，保留 SSH 会话。SOCKS 动态转发未实现。

连接／转发事件保留最近 500 条，可筛选、复制和导出 JSON，包含时间、分类、主机、事件与失败标记。事件不记录密码、终端输入输出或会话录像；日志持久化在本机工作区。

## 0.3.2 功能入口对齐

- 顶部主机库与保险库下拉分开；本地保险库覆盖主机、凭据、转发、已知主机和日志页面，切回时保留上次模块。
- 侧栏按 Hosts → Keychain → Port Forwarding → Known Hosts → Logs 排列。SFTP 位于顶部；本地终端位于主机工具栏或新标签页；设置与导入位于左下工作区菜单。
- 分组显示在主机区域，创建位于“新建主机”下拉；重命名／解散位于分组卡片右键菜单。
- 凭据库工具栏提供“新建私钥”与下拉“新建身份”；端口转发提供本地／远程新建菜单；搜索位于各模块顶部。
- 顶部加号、⌘T 和 ⌘K 进入搜索新标签，自动聚焦搜索；回车打开第一个匹配会话或主机。终端工具入口位于右上角。
- SFTP“选择主机”直接打开可搜索的选择面板，选择后停留文件页，复用该主机现有连接。远程栏标题可以切换主机。

入口对齐范围为已实现的本地功能。多保险库、Snippets、串口、Touch ID／FIDO2、私钥生成和团队功能尚无入口；不显示无操作的占位菜单。终端字体、配色和已有服务器／凭据不迁移。

## 0.3.5 私钥文本输入

凭据库和主机详情支持“粘贴文本”与“选择文件”两种私钥来源。新建私钥默认文本输入，可粘贴包含 BEGIN／END 行的完整 OpenSSH Ed25519 或 RSA 私钥；加密私钥填写对应口令。保存前检查格式与口令，支持 CRLF 换行和首尾空白。文本与口令分别保存在 macOS 钥匙串，配置及备份只保存来源等元数据。SSH、SFTP、跳板机与转发使用同一认证路径。

## 0.3.6 新标签分组与终端布局

新标签页先显示分组文件夹，下方仅显示未分组主机。点击分组查看其主机，再单击连接；搜索匹配分组名称以及主机名称、地址、用户名和标签。空分组有独立空状态，返回按钮恢复根目录。

搜索支持 `user@host`、`ssh user@host -p 2222`、IP、域名、`localhost`；直接按回车或点击“立即连接”。也可点击“快速连接”填写地址、用户名、端口并选择已有身份。相同地址、端口与有效用户名的已存主机会复用其凭据；新的临时目标只打开会话，不添加到主机库，临时密码仅用于当前连接。⌘T／⌘K 再次打开新标签会回到分组根目录并聚焦搜索。

顶部工作区按钮关闭系统焦点光效。终端移除浅色会话信息栏，增加内边距，右侧工具调整为深色圆角面板；状态由标签及断连提示展示，搜索、分屏和重连保留在快捷键、右侧工具及标签菜单。SFTP 保留独立连接信息栏。原始 Menlo 19、Dracula Green 与用户配置不迁移。

## 0.4.2 导航与工作区细节

SFTP 本地与远程面板增加固定置顶的 `..` 上级目录入口（根目录隐藏），支持双击和 Enter；导航行不计入文件数量，不进入传输、改名、权限、删除或拖动操作。主机库根目录只显示分组与未分组主机，进入分组再浏览其中的主机；搜索、标签与收藏仍可跨分组查找。左下角工作区菜单改为侧栏内的紧凑浮层，展示应用图标并取消系统焦点蓝框。Dock 图标外框扩大至 880/1024，内部 A 与琥珀色节点同步放大。

最近打开列表本轮仅提供新标签页界面设计，尚未写入连接历史功能。

## 0.4.3 同名会话与 SFTP 本地栏

同名会话统一显示 `(1)`、`(2)` 编号，按创建顺序分配，拖动标签不改变编号；关闭后重新编号，仅剩一个时恢复原名。编号用于顶部标签、已打开会话和代码片段目标。

SFTP 选择主机改为右栏内的选择页面，保留左栏操作，提供搜索、分组筛选和“本地”按钮。右栏可切换远程与本地，支持两个本地目录之间复制；连接已打开的主机时复用 SSH，独立 SFTP 连接不额外创建终端标签。切换栏位不会将已入队的任务改到新目标，本地复制拒绝自身路径及目录内部路径。

图标保留标准 macOS 外框，进一步增大 A 和琥珀色标记；系统渲染后的 A 宽度比 0.4.2 增加约 17%。应用包使用版本化图标资源，退出并重新打开应用后加载新的代码与图标。


## 0.4.4 标签、双栏尺寸与最近打开

顶部按固定按钮和标签实际总宽分配空间，剩余部分用于拖动窗口；两台远程会话加新标签时不再被空白拖动区挤掉，溢出时横向滚动，切换会话／打开新标签会滚到对应标签，加号始终位于滚动区外。

SFTP 改为稳定的两个容器，右侧主机选择器与本地／远程文件列表切换不会改变分割容器结构；原生文件表格按栏宽布局，列宽只影响栏内横向滚动。分隔条可拖动，拖到最小宽度后保存实际显示比例；窄栏展开筛选独占一行，操作、收藏和隐藏文件按钮保持可用。

新标签页的操作区下方显示“最近打开”，终端与文件记录分别最多 5 个目标、仅最近 7 天，同一目标重新打开更新时间并移到前面；区分 SSH、SFTP、本地终端和本地文件。默认显示终端记录；标题旁「显示 SFTP」默认关闭，勾选后同时显示 SFTP 和本地文件，SSH 始终保留显示。文件记录不会挤掉 SSH 记录。仅成功打开后记录，不记录失败的点击。单击回到相同目标的现有会话，已结束的终端可重新打开，SFTP 不额外创建终端；可移除单项或清空。页面每分钟修剪过期目标，重启保留有效历史，不自动恢复连接。

最近记录仅保存主机 ID 或安全的地址、端口、用户名／共享身份 ID；不保存密码、私钥、口令或私钥路径。重开使用当前主机和身份配置，移除目标或共享身份后清理不可用记录。已有不同身份、路由或独立私钥配置的连接不会被误复用；保存失败回滚历史改动，损坏工作区保持原文件。

Axon 图标的外板为 912/1024（原 880/1024），内部标记同比例调整；版本化图标资源随应用启动直接加载，避免系统沿用同 bundle ID 的旧图标缓存。保留 Axon 品牌形状、用户 Menlo 19 和 Dracula Green 配色。


## 0.4.5 主机编辑、凭据选择与点击范围

认证方式和私钥来源改为原生分段按钮，每一段都有完整矩形点击范围，明确显示选中状态，支持键盘方向键、空格及无障碍选择。主机卡片的收藏和编辑改为常显、横排的独立 32×32 按钮，与连接区域分开；按钮空白边缘也可点击。

“引用凭据”改为 38px 高的原生“登录凭据”选择框：整行可点击、图标和箭头清晰，可选“仅用于此主机”或凭据库中的共享身份，直接新建／编辑共享凭据。空凭据库说明原因和下一步。选择共享身份后显示它的当前用户名与认证方式，统一从身份编辑入口修改；切回独立设置保留本次未保存的输入。读取失败显示重试并禁止保存，避免覆盖尚未读到的秘密。

端口保留完整编辑草稿，只接受 1–65535 的十进制整数。非法内容、空值和越界值显示提示并禁止保存／连接，不能悄悄按旧端口提交。地址、用户名、名称、分组／标签、私钥来源／路径、跳板引用及转发字段在保存和连接前统一校验，兼容 IPv6、中文名称和含空格的私钥路径。快速连接同步检查显式端口；回滚行数限制为 0–1,000,000。密码／口令保留原值，私钥文本沿用 OpenSSH 格式校验。

## 0.4.6 SFTP 提示与传输状态

文件操作错误改为当前栏右下角的浮动提示，不占用路径栏与表头之间的空间。可手动关闭，6 秒后自动收起；重复错误重新计时，较长详情可滚动查看。工具栏、右键和拖放的传输校验错误统一显示在目标栏。

传输队列按状态显示颜色和图标：进行中为蓝色，失败为红色，完成为绿色，等待为琥珀色，取消为灰色。状态文字随界面语言显示，失败详情与状态同时保留，上传、下载和本地复制分别标注。

## 0.4.7 标签排序、主机分类与连接认证

终端标签使用原生拖动排序，拖至目标标签左／右侧分别插入前／后；右键也可左移、右移、移到最前或最后。顺序调整保留已打开的连接、同名编号和分屏关系。

主机工具栏的网格／列表按钮直接切换视图，同时作用于分组和主机。工具栏新增“新建分组”和“管理”；管理页可创建、重命名和删除分组／标签，删除分组将主机移到未分组并保留连接配置。标签改为独立标签块，回车／逗号添加，支持建议和移除；保存时也提交仍在输入框中的草稿。标签重命名和删除同步更新使用它的所有主机，空标签可独立保存在分类目录中。

主机详情的分组和跳板机采用完整的 38px 选择字段；跳板机可按名称、地址和分组搜索，显示用户名与地址，排除自身与会造成循环的路径。连接时缺少认证信息会打开 Axon 风格的认证窗口，可选择密码、私钥文本／文件、私钥口令及已有共享凭据。未勾选记住时凭据只保留在当前会话内存中；勾选后通过原有事务将元数据和钥匙串一起保存，失败回滚。

## 0.5.0 主机库监控与终端状态

监控位于「主机库」左侧，与主机、凭据等页面并列；顶部仍只有主机库、SFTP 和会话标签。主机卡片右键、主机详情的「查看状态」进入同一详情。概览直接展示可搜索的主机资源卡片，不再显示全部／在线／离线三张统计卡。终端工具栏增加「状态」，可切换到代码片段、外观或会话工具，查看详情时保留当前终端。

先连接 Linux SSH 主机，再打开监控。仅在监控页面或当前终端状态面板可见、Axon 位于前台且窗口可见时采集：概览订阅已连接目标，单机详情或终端状态只订阅当前目标。主机库普通页面、SFTP、代码片段、关闭侧栏、应用后台、隐藏和最小化均暂停采样；回到可见前台状态后自动恢复。未连接的保存主机只显示连接状态，监控不会自动连接或恢复全部主机。暂停与关闭监控不会断开 SSH。

| 模块 | 内容与交互 |
| --- | --- |
| 资源概览 | 系统、架构／CPU 型号、核数、运行时长；整体与每核心 CPU，User／System／Nice／IOWait／Steal；1／5／15 分钟负载及有限实时趋势 |
| 内存与磁盘 | 总量、已用、缓存、空闲、可用、Swap；挂载点容量、已用与可用，设备读写速率、IOPS 与忙碌时间 |
| 进程 | 最多 300 个进程，搜索、排序与只读详情；PID、用户、状态、线程、RSS 和参数。CPU 标为生命周期平均值，参数截断并遮盖常见密码／Token／URL 凭据，不采集环境变量 |
| 网络与 IP | 同时展示全部实际网卡的状态、IPv4／IPv6 地址分类、上传／下载速率和累计字节；已有 vnStat 时按接口显示真实历史，没有时说明原因 |
| NVIDIA GPU | 多设备选择、利用率、显存、温度、风扇、功率、驱动及驱动支持的 CUDA 版本、GPU 计算进程；需要服务器已有 nvidia-smi |
| Docker | 容器状态、健康、镜像、开始时间、端口、CPU、内存、累计网络／Block I/O 与只读详情；需要已有 Docker 和当前 SSH 用户的查询权限 |
| 终端状态 | 当前主机 CPU、负载、内存／Swap、网络与进程摘要，点击详情进入主机库，和代码片段切换时停止本面板订阅 |

采集通过现有、已认证 SSH 连接的独立 exec 通道执行固定只读命令，不往交互终端输入命令，不安装远端程序，也不修改服务器配置。目标地址、端口、实际认证用户名和完整跳板路径均相同的多个会话共享采样；不同跳板后相同内网地址保持独立。每个目标同一时刻只有一次采集，约每 5 秒更新。超时、响应过大、断线、缺少工具、无查询权限与尚未产生有效样本分别显示，失败或暂停保留带时间的上次快照，不将缺失数据显示成 0。

CPU、磁盘和网络速率按连续样本的服务器 uptime／计数差计算；首次采样、恢复前台、重连、计数回退或服务器重启后重新建立基线，须连续两次有效样本才显示速率。每个目标历史最多 120 次，仅存在内存；暂停保留已有图表，恢复时不将中间暂停的时间伪装为持续采样。监控快照和自动采样不写入 workspace.json、日志或钥匙串。

采样超过 8 秒显示超时并取消其子通道读取；底层 Citadel 的 SSH 通道创建最多等待 15 秒，尚在创建的旧请求保持为进行中，清理完成后才能启动下一次。关闭子通道保持父 SSH 与 PTY。当前仅支持 Linux /proc；ps、GNU df、ip、vnStat、nvidia-smi 和 Docker 各自缺失时显示能力说明。网络历史来自服务器现有 vnStat 数据库，不额外建立持久化数据库。IP 本轮展示实际地址与内网／公网等分类；地区、ASN 和地图尚未接入外部数据源，不自动发送服务器地址。GPU 的 CUDA 版本表示驱动支持版本，不代表已安装的 CUDA Toolkit。

## 0.5.1 分组基础设置与界面行为

分组的新建与编辑在主机库右侧详情中进行，包含用户名、端口、密码／私钥、共享凭据和跳板机。分组内的新建主机默认继承已有基础设置，各项可单独关闭“使用分组”并覆盖。现有主机保留原配置，可主动启用继承；连接使用当前分组设置，已认证会话保留实际端点及路由。密码、私钥和口令继续只保存到 macOS 钥匙串。重命名分组保留继承关系；删除分组保留主机，并将有效设置和需要的认证材料保存到主机。

标签使用独立的“管理标签”入口；分组通过卡片编辑按钮或进入分组后的“编辑分组”打开右侧详情。主机工具栏同时提供网格与列表两个按钮，选中项直接表示当前布局。没有终端或新标签时回到主机库。

传输队列为空时自动移除底部面板，有任务时可以收起为计数条并再次展开，新任务自动展开，收起不取消传输。应用图标交给 macOS 按应用包统一呈现，避免启动时用直接读取的资源替换 Dock 图标。

## 0.5.2 监控操作与分类设置

监控概览支持卡片和列表。卡片统一为 202pt 高，不因采样状态或名称换行增高；卡片详情和“连接／打开终端”是独立点击区域，详情也提供该按钮。直接登录优先打开同一实际用户名、端点和完整跳板路由的现有 SSH 终端；没有有效会话时使用对应保存主机的分组继承、共享凭据或临时连接原认证信息。单击详情和普通监控刷新不会创建连接。

磁盘信息占整页宽度，容量挂载点和设备 I/O 分开网格展示。根挂载和数据卷默认可见，系统及容器挂载可展开查看；长路径保持单行、省略中间部分，悬停和复制可获取完整路径。网络同时显示全部网卡，包括 DOWN、桥接、回环和仅提供地址的接口；每个接口展示全部 IPv4／IPv6、状态、速率与累计字节。Docker 的“隐藏未运行容器”只改变显示，关闭后恢复全部容器；状态以 Docker 的机器字段为准，暂停、重启、停止和未启动均可隐藏。

主机详情不再提供“新建共享凭据”，选择已有凭据和编辑当前共享凭据保留；创建在凭据库进行。

设置分为通用、终端、外观、键盘与剪贴板、连接、关于与快捷键，采用草稿及显式保存／撤销。新增本地 Shell／启动目录／登录 Shell、光标形状与闪烁、四种完整 ANSI 配色预设和独立文字／背景／光标色、Option Meta、退格 Control-H、鼠标事件、铃声、中键粘贴、多行粘贴确认，以及 SSH／SFTP 直连 TCP 超时。设置实际连接到终端或连接行为，非法字段与保存失败不改变已生效配置。旧配置可加载并保留原字体和颜色，多行粘贴确认默认关闭。

字体、配色、回滚、光标及键盘行为在保存后应用于已打开终端；减少回滚会丢弃超出范围的历史。本地 Shell／目录仅用于新本地终端，TCP 超时仅用于新连接；认证仍遵循当前 Citadel 的独立 10 秒限制。分类与终端侧栏功能参考 [Termius 官方说明](https://docs.termius.com/getting-started/what-is-termius)，当前没有实现账户同步或自定义全局快捷键。

监控概览使用主机库分组，默认展示分组入口和未分组主机；进入分组后可切换卡片／列表、组内搜索或返回。根页搜索跨全部分组，也可显式打开“全部主机”。分组入口显示主机和连接数量，连接／打开终端使用有悬停及按下反馈的 116×36pt 平面按钮，详情与登录动作各自独立。

## 0.5.5 黑底／白底图标选择

设置 → 通用 → 程序图标提供黑底白标和白底黑标，两款都保留黄色节点及缩小后的 Logo 比例。旧配置默认保留黑底；点击卡片只改变草稿，保存后同时更新应用内 Logo、Dock 以及 Finder 的程序图标。重启记住已保存选择，撤销恢复当前保存的图标。程序包自带两款完整尺寸 ICNS，发布默认图标继续使用黑底。

## 0.5.7 终端设置、统一侧栏与会话退出

设置直接使用工作区左侧栏：点击底部「设置」或 ⌘,，原主导航替换为通用、终端、终端配色、键盘与剪贴板、连接、导入、快捷键和关于；「返回工作区」回到主机库。主导航与设置分类采用相同的原生整行按钮，图标、文字、空白和边角均可点击。终端右侧工具中的字体与配色入口跳转到同一套设置，避免两套控件行为不同。

终端字体从本机已安装等宽字体菜单选择，字号可直接输入或用 42pt 加减按钮调节（10–40pt）；实时预览不启动进程或连接。字体、回滚与光标按用途分卡，保存后同步所有已打开终端。无效字号会禁止保存，切换分类仍保留输入供修正。配色说明明确默认文字、背景、光标和 16 个常规／高亮 ANSI 色的作用；目录、可执行文件与错误等仅为用色示例，实际由程序、Shell 主题及 LS_COLORS 决定。24 位 RGB 输出直接指定颜色，不依赖 ANSI 调色板。

导入成为设置的独立类别。选择 Tabby YAML 后再确认导入；页面说明支持字段、地址／端口／用户名去重和凭据处理。选择文件与浏览设置不自动提交，导入确认独立于偏好保存。

正常远程 PTY EOF、本地 Shell exit 0 和取消新连接认证会关闭对应标签／分屏；剩余分屏或相邻标签接续，最后一个终端关闭后返回主机库。非零退出、连接失败及异常断线保留诊断，旧连接回调不能关闭已重新连接的会话。Citadel 的公开 PTY 接口无法区分正常 EOF 后立即关闭整个 SSH 传输与异常传输关闭，此边界保留诊断。

监控详情的五个分类统一为整块 38pt 原生按钮。网络卡片按每行实际所需最大高度排版，即使地址数量不同也保持同排等高；完整 IPv4／IPv6 与无地址信息继续展示。

“系统及容器挂载”改为整行原生展开按钮，箭头、标题、文字旁留白及整行边角均可点击，支持键盘与辅助功能，默认保持收起。CPU 逻辑核心使用同样的展开控件。


## 0.6.0 导入、导出与加密云备份

设置 →「导入与导出」支持 Tabby YAML、OpenSSH config、Termius 兼容 CSV、PuTTY `.reg`（UTF-8 / UTF-16）导入。选择来源格式和文件后，先预览新增数量、重复数量与未迁移字段，再点击「导入主机」立即保存。按地址（忽略大小写）、有效端口与用户名去重，重复项保持原凭据；导入的跳板引用重新映射到新主机或已有重复主机。Include 文件不自动读取，Match、ProxyCommand、SSH agent、登录脚本与源端口转发不执行、不迁移；PuTTY PPK 需要先转为 OpenSSH 私钥。SecureCRT、Xshell、MobaXterm 专有／加密会话格式尚未支持。

主机导出支持 Tabby YAML、CSV、OpenSSH config，以分组继承和共享身份解析后的有效配置导出，不含密码、口令或文本私钥。CSV/YAML 保留分组、标签、收藏和跳板引用；OpenSSH 使用唯一的安全别名，保留连接字段和 ProxyJump，不保留分组/标签/收藏。CSV 建议字段 `hostname,label,username,port,group,tags,identity_file`，另支持 `id,jump_host,auth,favorite,password` 等；额外列会在导入预览中提示。CSV 含密码时仅写入 macOS 钥匙串，不进入工作区文件。

Axon `.axonbackup` 工作区备份保留主机、分组继承、凭据元数据、转发规则、代码片段、主题、偏好、书签和已知主机信任记录；不含日志和最近记录，也不携带云连接配置。默认导出未加密的元数据 JSON；开启加密后可选择携带密码、口令与粘贴的私钥，使用随机盐、PBKDF2-HMAC-SHA256（200000 次）和 AES-256-GCM。备份密码至少 8 个字符，无法找回且不保存。文件私钥只记录路径，不读取或复制内容。备份上限 20 MB。

完整恢复先验证版本、内容和引用，再显示当前与备份主机数量确认。恢复替换当前工作区，需要先关闭终端并停止转发；旧配置保存到 `workspace.json.backup`，配置与钥匙串写入失败时回滚。没有携带凭据的备份不会复用旧钥匙串值，需要重新填写凭据。跨电脑的私钥文件路径、字体、Shell 和本地目录需按新电脑实际环境调整，恢复不会启动连接。

设置 →「云备份」提供两种加密备份/恢复方式，0.7.0 起可选择启动后自动备份；尚不支持自动合并或冲突解决：

- **iCloud Drive / 同步文件夹**：在系统保存窗口选择 iCloud Drive 或其他同步文件夹，macOS/网盘客户端负责同步；不要求开发者会员。原生 CloudKit 则需要 Apple Developer Program 会员。依据 [Apple 的 iCloud 配置说明](https://help.apple.com/xcode/mac/current/en.lproj/dev52452c426.html) 与 [CloudKit 启用要求](https://developer.apple.com/documentation/cloudkit/enabling-cloudkit-in-your-app)。
- **S3 兼容服务**：填写 HTTPS Endpoint、S3 Region ID、空间名、对象路径和 AK/SK；七牛华东预设为 `https://s3.cn-east-1.qiniucs.com` / `cn-east-1`，其他区域依据 [七牛服务域名表](https://developer.qiniu.com/kodo/4088/s3-access-domainname)。七牛使用控制台的 **S3 空间名**，不是必然等于原空间名；区域不是 z0/z1。签名采用 [七牛支持的 SigV4](https://developer.qiniu.com/kodo/4093/s3-authentication)。连接配置独立存储在本地 `cloud-backup.json`，0.9.1 起连接字段自动保存，SK 仅保存到 macOS 钥匙串，不包含在工作区备份中。

每次云备份先在本机加密；S3 上传发送 `If-None-Match: *`，服务支持时拒绝覆盖已有对象，失败不降级为普通 PUT。0.9.1 起可开启「每次备份生成新文件」，自动生成带时间与唯一标识的对象路径；恢复先列出备份，选择后输入原备份密码，再确认恢复。[AWS 条件写说明](https://docs.aws.amazon.com/AmazonS3/latest/userguide/conditional-writes.html)。七牛文档列出 PUT/GET 兼容，但没有明确承诺条件 PUT 的语义；当前仅完成官方签名向量与本地模拟传输验证，尚未使用真实七牛账号验证，不承诺任意 S3 服务都支持条件写。HTTP 仅允许回环本地测试，签名请求不跟随重定向，上传/下载限 20 MB，网络超时 60 秒。

## 0.6.2 备份密码状态

备份密码在每次输入、删除及清空时同步。密码不足 8 位时，云备份「保存到文件夹」、S3「上传备份」和本地加密备份「保存备份」禁用；重新输入有效密码后恢复。保存入口再次校验当前密码，原生设置按钮同时遵循父级禁用状态。备份密码仍只保留于当前页面内存，不保存。

## 0.7.0 启动后自动备份

设置 →「云备份」→「自动备份」可分别开启「启动后自动备份到 iCloud / 同步文件夹」和「启动后自动上传到 S3」。先选择已有文件夹；使用 S3 时先在上方保存连接配置。0.7.2 起共用上方至少 8 位的备份密码和携带凭据选项，再点击「保存备份设置」。保存设置不会立即上传，可点击「立即备份」检查结果。此设置独立于页面底部的偏好「保存」。默认两个目标都关闭。

启用后，每次启动 Axon 在后台执行一次；关闭后重新启动才算下一次启动，窗口或设置页面重复出现不会重复触发。自动备份使用本机钥匙串记住的共用密码，密码不进入 JSON 配置或网络请求；仅使用手动备份不会保存密码。重新打开页面会将记住的密码载入顶部；启用自动目标时，清空顶部密码后需重新填写至少 8 位才能保存或立即备份。输入新密码并保存后用于后续备份；旧备份仍需要其原密码。关闭两个目标并保存会关闭自动任务并移除记住的密码，已有备份文件保留。钥匙串暂不可读取时，后台失败并记录结果，避免在启动时弹密码提示。

0.7.1 起自动备份默认使用 `Axon-latest.axonbackup`；0.9.1 可选择每次生成新文件。关闭新文件选项时，文件夹通过同目录临时文件原子替换，S3 覆盖自动路径前缀下的同名对象；每次启动或点击“立即备份”更新同一份文件，不改变手动 S3 对象路径，不自动删除此前版本的历史文件。加密与备份范围沿用 Axon 备份，私钥文件仅保留路径。后台使用启动时的工作区快照，不保存未提交的偏好，也不读取或覆盖无法解码的工作区。

页面显示两个目标各自的最近时间、结果与文件位置，一个目标失败仍尝试另一个。文件夹成功仅表示文件已在本机写入，iCloud 上传由 macOS 完成；网络失败、授权过期或文件夹移除后，可修复配置并点击「立即备份」，也会在下次启动重试。没有定时重试或自动恢复／合并。取消任务会等待后台停止；已经写好的文件保留。


## 0.7.1 恢复密码确认与固定自动备份

从本地文件、iCloud 文件或 S3 恢复加密备份时，每次单独弹出空白的安全密码输入框，不复用手动备份输入值或钥匙串记住的自动备份密码。密码错误或为空可重试，取消不修改工作区。解密成功后显示恢复确认，列出实际携带的密码／口令与文本私钥数量；无凭据备份明确提示恢复会清空现有对应凭据，并使用“恢复并清空凭据”按钮。创建备份时需勾选携带凭据，单独加密不会包含主机密码；已经不含凭据的旧备份无法恢复缺失的内容。

自动备份更新固定文件 `Axon-latest.axonbackup`；文件夹保留旧文件直到新内容完整写入并原子替换，S3 对自动对象显式允许覆盖。手动 S3 上传仍防止意外覆盖已有对象。


## 0.7.2 统一备份选项与关闭窗口隐藏

云备份顶部的密码和“携带密码与粘贴的私钥”同时用于手动和自动备份。自动区域只选择 iCloud／同步文件夹、S3 目标，并在需要时选择文件夹；不再重复设置密码、携带凭据或 S3 路径前缀，已有前缀保留并只读显示固定对象。点击“保存备份设置”保存这些共用选项和目标；启用自动备份时密码记在本机钥匙串，重新打开页面自动载入顶部。清空顶部密码会立即禁用手动加密备份及“立即备份”，改变密码或携带选项后需保存再执行自动备份。禁用两种目标并保存会移除记住的密码，当前顶部输入仍供手动操作使用。

恢复密码使用与应用一致的白色面板、锁图标、灰色安全输入框和矩形按钮。每次打开为空，错误信息使用当前界面语言，清空时不能提交；回车继续、Escape 或右上角关闭取消。恢复前仍需输入原备份密码并确认替换工作区。

点击主窗口红色关闭按钮或关闭窗口命令只隐藏同一窗口，保留连接、转发、备份任务与未保存草稿；点击 Dock 图标恢复同一窗口。Dock 右键“退出”、应用菜单“退出”或 ⌘Q 才完整退出并清理任务。认证／恢复弹窗的关闭仍代表取消该操作。隐藏后监控采样沿用原有可见性规则暂停，SSH 连接与其他后台任务保持。

## 0.8.0 工作场景、目录联动与运维工具

- **目录联动**：终端右侧会话工具可在 SFTP 打开当前目录；选区右键可定位路径。OSC 7 报告须来自当前连接地址，嵌套 SSH 的不同主机报告不用于外层文件导航。Shell 未报告时可插入「上报当前目录」命令，检查后运行。自动跟随按会话开启，默认关闭。文件夹右键「在终端进入此目录」复用匹配账号、认证配置及跳板路线的终端，插入安全引用的 cd 命令，供检查后按回车。
- **参数片段**：引号外的 `{{参数}}` 支持默认值、必填及文本／数字／路径类型；填写后预览展开命令，再插入或运行。每个参数作为一个 POSIX Shell 参数引用，避免空格、引号及命令替换改变语义。引号内／转义的大括号继续作为原命令文本，兼容 Docker Go 模板。含参数的 here-document 暂不支持。
- **工作场景**：新标签页「常用工作场景」可新建，或保存当前终端组合。保存主机引用、顺序、初始目录、双栏布局、文件／日志路径和转发规则。打开为独立工作区标签，内部切换终端、SFTP 与日志；使用当前凭据重新建立连接。场景配置进入工作区和加密备份，不保存终端输出或秘密。关闭场景清理其会话；仍为其他场景或手动代理提供连接的会话保留。
- **日志查看器**：SFTP 普通文本文件右键「查看日志」打开独立标签。默认末尾200行，支持跟随／暂停、搜索、过滤、错误高亮、复制和导出已加载内容；缓存最多10000行及2MB。搜索范围为已加载内容。文件缺失、截断／替换及断线显示状态；轮转通过大小与边界内容尽力检测，快速轮转不承诺零遗漏。UTF-8 文本支持中文分块和长行，二进制文件不进入查看器。
- **目录比较**：SFTP 双栏工具菜单可比较两个当前目录，递归按内容摘要判定差异，修改时间只作辅助；支持隐藏文件开关、忽略规则和取消。预览新增、修改、相同、目标独有及冲突项目，勾选后按固定清单单向传输，保留目标独有文件。传输前和提交前再次检查内容变化；不跟随符号链接，同名文件／目录及本地大小写冲突不自动合并。扫描最多50000项。
- **动态 SOCKS5**：端口转发中新建「动态 SOCKS5」，默认 `127.0.0.1:1080`；可复制 `socks5h://` 地址。支持无认证 TCP CONNECT、IPv4／IPv6／域名请求，域名原样交给 SSH 服务器解析。首版仅监听回环地址，不支持 UDP、BIND 与 SOCKS4，不修改系统代理。停止释放监听及子连接，SSH 断线停止规则；应用重启后保持停止，场景可显式配置打开时启动。

## 0.9.1 云备份历史、恢复列表与配置保存

设置 → 云备份的「每次备份生成新文件」同时控制手动和自动备份。开启后每次使用 UTC 时间、毫秒及 UUID 命名，保留历史文件与 S3 对象，文件发布及上传都拒绝覆盖；关闭时自动备份保持更新 Axon-latest，手动 S3 保留已有对象保护。旧配置默认关闭，避免改变既有备份方式。

文件夹恢复先选择目录并展示备份列表；S3 恢复先按 ListObjectsV2 分页列出空间内的 .axonbackup 对象。列表按时间倒序，可搜索并显示大小；用户选择后才下载、输入原备份密码并确认恢复。[S3 ListObjectsV2](https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListObjectsV2.html) 账号需有列举对象权限；不支持列举的服务会显示错误。

S3 Endpoint、区域、空间、路径、AK 和新文件策略在编辑时保存到独立 cloud-backup.json，重开页面和应用会回填；SK 在输入后存入钥匙串，不写入配置文件。清空 SK 输入保留已保存的钥匙串值；读取钥匙串失败时保留已加载的连接字段，不以空值覆盖密钥。
